# WaterWise — Outputs Directory

This directory stores outputs generated by the PySpark data processing and anomaly detection pipelines.

## Output Structure

```
outputs/
├── README.md
├── parquet/
│   ├── cleaned_water_data/        # Partitioned Parquet dataset of cleaned records
│   ├── hourly_aggregates/         # Precomputed hourly consumption metrics
│   ├── daily_aggregates/          # Precomputed daily consumption metrics
│   └── fixture_aggregates/        # Consumption metrics by fixture and water type
└── reports/
    ├── pipeline_summary.json      # Summary metrics (rows in/out, cleaning stats)
    └── statistical_anomalies.csv  # Top flagged statistical anomalies for offline review
```

## Storage Formats
* **Parquet**: Columnar format with dictionary encoding and Snappy compression. High throughput for analytical queries in PySpark and DuckDB/Pandas.
* **JSON / CSV**: Summary metadata and extracted anomaly records for reporting and dashboard consumption.
